# Chinonso Onyebuagu — Portfolio

A responsive portfolio website presenting selected work, skills, experience, and contact details. The interface includes dark and light themes, interactive 3D visuals, project and service sections, and a contact form that opens a prefilled email draft.

## Tech stack

React 19, TypeScript, Vite, Tailwind CSS, Three.js, and React Three Fiber.

## Run locally

Use Node.js and npm:

```sh
npm install
npm run dev
```

For a production build or local preview:

```sh
npm run build
npm run preview
```

The contact form uses a `mailto:` link, so submitting it opens the visitor's email application rather than sending data to a server.
